# Surface: Workbench site (index.html — Prompts, Repos, Guides)

Mode: Experience (the gallery leads); repos and guides are Operate/Read rooms inside it.
Audience: creators learning AI, mostly non-coders. Job: find a prompt to copy and learn why it works; find a tool; follow a recipe.
Chosen: the category standard (canon), modelled on opennana.com at the user's request.

## Direction contract
THESIS: A prompt gallery played straight at full craft — the image wall leads, search and pill filters sit directly above it — refusing only one category habit: prompts shown as an undifferentiated text blob; ours are annotated by role.
OWN-WORLD: Near-white cool ground (#f8fafc), white rounded cards (12px) with soft offset shadows, slate ink, pill chips whose active state is pale cyan with a cyan hairline, one cyan→blue primary button, system sans throughout, mono only for prompt text. Anatomy colours are the only other hues.
STORY: Visitor sees images immediately, narrows by model or subject, opens one, reads the colour-coded prompt, copies it; same pattern for repos and guides.
FIRST VIEWPORT: Sticky white header (wordmark left, Prompts / Repos / Guides right). Bold page title + one-line subtitle, then the search pill + gradient Search button + live count on one row, then a light filter panel (source, model and subject chip rows; chips wrap on desktop and scroll sideways at 600px and below), then the masonry wall starting above the fold. Primary action: search / open a card.
FORM: canon (standing exit), user-pinned to opennana.com; seed: seed:4b55daa8dc9506dc. Signature interaction: the detail sheet's "Highlight anatomy" toggle that colours each phrase by role. Motion: cards lift slightly on hover; the sheet slides up from the bottom on mobile.
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
